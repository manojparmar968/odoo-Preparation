Don't want to expose your secret key always use env File 
Step 1 Install python-dotenv --> Install once.
    pip install python-dotenv
    pip3 install python-dotenv
    Add it to requirements.txt
        python-dotenv
Step 2 Create .env --> At the root of your project create
    .env
Step 3 Update .gitignore
    .env
*.env
.env.*
